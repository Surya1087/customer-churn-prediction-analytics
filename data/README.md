# Data

Download the [IBM Telco Customer Churn CSV](https://raw.githubusercontent.com/IBM/telco-customer-churn-on-icp4d/master/data/Telco-Customer-Churn.csv) and save it as:

`data/raw/WA_Fn-UseC_-Telco-Customer-Churn.csv`

The project does not commit the raw dataset. The commonly distributed dataset contains 7,043 rows and 21 columns, with `Churn` as the target. Review the host's usage terms and retain IBM attribution in any redistribution.
